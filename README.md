# waifu-avatars

Public avatar images for the homelab waifu Discord bot.

Put images in `avatars/` (square PNG, about 256–512 px) and reference them in `personas.toml` as:

```
https://raw.githubusercontent.com/<user>/waifu-avatars/main/avatars/<file>.png
```

Discord caches avatars by URL: to change a picture, upload it under a new filename.
